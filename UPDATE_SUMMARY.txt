[UPDATE SUMMARY - 2026-02-12 04:30] NOTIFICATION NAVIGATION REFACTOR

1. OVERVIEW
   This update refactors the notification navigation system to seamlessly direct users to the 
   appropriate tab within their dashboards upon clicking a notification. It specifically addresses 
   review notifications for both Volunteers and ONGs.

2. KEY CHANGES
   
   A. Dashboard Navigation Logic:
      - [VolunteerDashboard.tsx] updated to use `useSearchParams` from `react-router-dom`.
      - Tabs now sync with the `?tab=` URL parameter.
      - Default tab behavior preserved if no parameter is present.
      - Clicking a notification with `?tab=feedbacks` now correctly activates the Feedbacks tab.

   B. Notification Links (SQL):
      - Updated `notify_reviews` function in migration scripts.
      - Changed ONG review notification link from `/ong-dashboard?tab=reviews` to `/ong-dashboard?tab=feedbacks` 
        to match the existing tab identifier in the ONG dashboard component.
      - Volunteer review notification link confirmed as `/dashboard?tab=feedbacks`.

   C. Consistency:
      - Ensured that notification types `volunteer_reviewed` and `ong_reviewed` point to valid routes.
      - Verified that `OngDashboard.tsx` correctly handles the `tab` query parameter.
